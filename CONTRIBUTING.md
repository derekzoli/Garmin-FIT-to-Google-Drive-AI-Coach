# Contribuire / Contributing

**IT:** Sono benvenute correzioni, screenshot **anonimizzati**, verifiche con nuove versioni di Home Assistant, traduzioni e miglioramenti alle istruzioni. Apri una issue o pull request descrivendo versione dell'add-on, comportamento osservato e test effettuato. Non condividere credenziali, token, file FIT reali, route GPS o screenshot con identificativi personali. Se modifichi la guida, indica quali passaggi sono stati verificati sul campo e quali sono ipotesi.

**EN:** Corrections, **redacted** screenshots, validation on newer Home Assistant releases, translations and documentation improvements are welcome. Open an issue or pull request stating the add-on version, observed behavior and test performed. Never submit secrets, OAuth tokens, real FIT files, GPS tracks or screenshots with personal identifiers. Clearly distinguish tested behavior from proposals.
