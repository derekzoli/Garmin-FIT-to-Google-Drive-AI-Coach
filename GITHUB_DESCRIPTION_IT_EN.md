# Descrizioni per GitHub / GitHub descriptions

## Nome repository / Repository name
`garmin-fit-to-google-drive-ai-coach`

## Descrizione breve IT
Sincronizza automaticamente gli allenamenti Garmin (.FIT) su Google Drive tramite Home Assistant e rclone, per analizzarli con un chatbot AI senza sviluppare API personalizzate.

## Short description EN
Automatically sync Garmin FIT workouts to Google Drive via Home Assistant and rclone for AI-assisted coaching, without building a custom API.

## Presentazione IT
Una guida passo passo per trasformare i dati del proprio Garmin in un diario di allenamento consultabile da un assistente AI. Home Assistant intercetta ogni nuova attività, scarica il file FIT e avvia rclone per trasferirlo su una cartella Google Drive privata. Con un chatbot che dispone di accesso autorizzato alla cartella ed è in grado di leggere i FIT, si possono richiedere analisi, confronti e suggerimenti di allenamento senza scrivere un backend o integrare API personalizzate. Include una copia di sicurezza programmata, esempi YAML e indicazioni su sicurezza e privacy.

## About EN
A step-by-step, tested guide to make Garmin workout data accessible to an AI assistant. Home Assistant detects new Garmin Connect activities, downloads FIT files and uses rclone to copy them into a private Google Drive folder. With an AI chatbot that has authorized Drive access and can process FIT data, you can request workout analysis, session comparisons and coaching suggestions without writing a dedicated backend or custom API integration. Includes YAML examples, a scheduled fallback and privacy guidance.
